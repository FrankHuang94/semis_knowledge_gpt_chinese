# Technical Diligence

本模块训练如何把技术主张拆成可验证命题，并跨performance、manufacturing、software、reliability、supply与deployment收集证据。

## 核心文章

- [Technical Diligence Playbook：如何拆 Claim、验证 Evidence、识别 Scale-up Risk](technical_diligence_playbook.md)

## 学习结果

完成后应能建立claim/evidence/falsification matrix，区分prototype与production，审计benchmark与yield definitions，设计跨团队访谈，并输出带confidence、unknowns与next tests的decision memo。
