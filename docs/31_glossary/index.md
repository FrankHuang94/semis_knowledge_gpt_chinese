# Glossary

Glossary 用于快速恢复上下文，不是主要学习路径。每个条目只有一句 intuition、prerequisite 与一个 canonical deep-dive link；mechanism、trade-off 和 strategy 只在核心文章中解释。

源数据位于 `data/glossary.csv`，运行 `scripts/generate_glossary.py` 可生成排序后的参考表。


## 深化手册

- [工程基础概念与术语手册](engineering_terms_handbook.md)：把 114 个术语扩展为系统位置、机制、测量、常见混淆与工程追问。


- [进阶工程术语手册](advanced_engineering_terms_handbook.md)：新增计算、存储、互连、物理系统、软件运维、标准与战略术语，并连接量化、故障和产品状态。
