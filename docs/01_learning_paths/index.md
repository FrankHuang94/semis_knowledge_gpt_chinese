# Learning Paths

知识库按任务组织阅读顺序，而不是要求按学科目录顺序学习。

- [AI Datacenter Engineering Core](ai_datacenter_core.md)：主路径，预计 60–80 小时，完成后能够把 workload 映射到 compute、memory、network、package、power 与 thermal。
- Conference Prep（规划中）：在 Hot Chips、OFC、GTC 或 OCP 前快速补 prerequisite。
- Technical Diligence（规划中）：面向 startup、供应商或 acquisition target 的验证路径。
- Product Architecture Reverse Engineering（规划中）：从 spec 与 block diagram 反推 architecture。
