# Conference Inbox

这里是 Hot Chips、ISSCC、OFC、SC、GTC、OCP 等会议材料的临时入口。Inbox 不是事实数据库：进入此目录的内容默认尚未完成全文核验，不能直接用于 product status 或关键规格表。

## 工作流

1. 复制 NOTE_TEMPLATE.md 建立一份记录，文件名使用 YYYY-MM-DD_event_session_slug.md。
2. 保存原始 URL、页码或视频时间戳；把每条主张拆成独立 claim。
3. 标注 [Primary Source]、[Independent]、[Vendor Claim]、[Estimate] 或 [Inference]。
4. 对照已有 article、company、product、standard 与 interface records，避免重复。
5. 完成 prerequisite、backlink、strategy implication 与 open-question 更新。
6. 通过 review 后，把稳定内容迁入 docs 或 data；原始 note 保留并标记 processed。

未填写 measurement boundary、as-of date 或 product status 的数字不得迁入 authoritative records。处理完成的定义不是“读完”，而是下游链接和待验证问题已经落地。
